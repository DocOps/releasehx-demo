== Key Features Demonstrated

=== Metadata Display

* Type badges (Feature, Bug, Improvement)
* Part badges (UI, API, Security, Performance)
* Tag badges (enhancement, breaking, security, etc.)
* Ticket links with issue numbers
* User assignments
* Git commit references

=== Layout Flexibility

* Grouped release notes by category
* Changelog-only or notes-only layouts
* Multiple frame styles (cards, lists, tables, admonitions)
* Custom type/part ordering
* Dark mode and custom CSS support
